# 重师 CAS 登录自动填充

一个用于重庆师范大学统一身份认证登录页的 Chrome 扩展：自动填充已保存的账号密码，并尝试识别页面验证码。

> 仅供个人学习与在本人有权使用的账号上使用。验证码识别基于通用 OCR，面对扭曲、重叠或干扰线较多的验证码可能出现错误；提交前请自行核对验证码输入框内容。

## 功能

- 首次使用时在页面内设置账号与密码，之后自动填入。
- 点击验证码图片刷新验证码后，等待新图加载并重新识别。
- 登录页右下角提供“修改已保存账号”按钮。
- 账号密码仅保存在当前 Chrome 用户配置的扩展本地存储中。

## 安装到 Chrome

1. 下载或克隆本仓库到本机，并保持文件结构完整，尤其不要删除 `lib/eng.traineddata` 和 `lib/tesseract.min.js`。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的项目根目录。
6. 安装完成后，首次加载如提示存储权限，请允许。

代码有修改时，回到 `chrome://extensions/`，点击扩展卡片上的刷新按钮，然后刷新登录页。

## 使用方法

1. 打开 <https://csxrz.cqnu.edu.cn/cas/login>。
2. 第一次进入时，在“设置 CAS 登录信息”窗口填写用户名和密码，点击“保存并填入”。
3. 扩展会自动填入账号、密码，并尝试识别当前验证码。
4. 点击验证码图片会刷新验证码；新图片加载完成后，扩展会再次识别并更新验证码输入框。
5. 提交登录前请核对验证码；若识别错误，请手动修改或刷新验证码后重试。

## 修改已保存账号

点击登录页右下角的“修改已保存账号”，重新输入账号和密码并保存即可覆盖旧信息。

## 项目结构

```text
captcha-auto-fill/
├── manifest.json          # Chrome 扩展配置
├── content.js             # 登录页填充与验证码识别逻辑
├── background.js          # 预留的扩展后台脚本
└── lib/
    ├── tesseract.min.js   # Tesseract.js
    └── eng.traineddata    # 英文/数字 OCR 语言数据
```

## 注意事项

- 扩展仅匹配 `https://csxrz.cqnu.edu.cn/cas/login*` 页面。
- 账号和密码保存于当前 Chrome 用户配置的扩展本地存储；请勿在共享电脑或共享 Chrome 配置中保存敏感账号。
- 当前验证码包含字符重叠、旋转和干扰线，通用 OCR 的准确率有限。
- 本项目不应用于未经授权的账号、网站或绕过安全控制的用途。
